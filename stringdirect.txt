ClassDelta Resource Range Index

Ⅰ - Log Rules/日志规则
All changes must be logged into the index once made.
所有修改需要在完成时写入索引
Eg.
Date/日期     Range/号段          Comment/注释
[261108]        00000~99999        Initialize directory
//Date format is in YYMMDD. Both gaps are 8 spaces in length. Do not skip zeroes! Comments should be in Chinese (zh-Hans/zh-Hant are all accepted) or English. Additional comments can be added through double slashes like this, and occupy entire rows.
//日期格式为年月日。两个空位均长8个空格。请勿省略零！注释语言应为中文（简体繁体均可）或英文。更多注释可以像这样通过双斜杠添加，并占据一整行。

Ⅱ - Main Index Rules/总索引规则
示例/Eg.
delta00000
//All ranges include endpoints, .axaml s include related .cs s./所有区间包含端点，.axaml文件包含相关的.cs文件。
//Range Code Rules/号段码规则:
0000X00
X=Rank Letter/级别字母, A=Root Category/根分类, B=Secondary Category/次级分类, C=Single Interface/单个界面; 00=Number/标号
Eg. ROOTA02，0001B09，0212C37
//First four digits: If this is an A category, then fill in ROOT; if this is a B category, the first 2 digits are 00, 3rd~4th digits is its A category number; if this is a C category, the first 2 digits is its A category number, 3rd~4th digits is its B category number.
The 5th digit: This range's ABC category.
Last 2 digits: The identification number under the current ABC category.
Such as 0212C37 is the 37th interface under 0002B12 under ROOTA02.
//前四位：若为A分类，则填入ROOT；B分类前2位为00，3~4位为A分类标号；C分类前2位为A分类标号，3~4位为B分类标号。
第5位：为ABC分类。
末两位：为该ABC分类下序号。
比如0212C37为ROOTA02下0002B12下的37号界面。
